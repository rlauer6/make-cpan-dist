# CPAN::Maker 2.0.8 Release Notes

**Release Date:** 2026-08-18

---

## Overview

Version 2.0.8 focuses on **build reproducibility** — sorted MANIFEST
files, timestamp-free `Makefile.PL` output, and a more robust
templating system — alongside a collection of build-system
modernisation improvements delivered via updated
`CPAN::Maker::Bootstrapper` managed files.

---

## What's New

### Build Reproducibility (`CPAN::Maker`)

- **Sorted MANIFEST** — A new `_sort_manifest` method is injected as a
  build step between `make manifest` and `make dist`. It sorts
  MANIFEST entries using a case-insensitive primary key with a
  case-sensitive tiebreaker, eliminating non-deterministic ordering
  that could arise when entries differ only in case (e.g. when
  packaging modules with mixed-case
  namespaces). ([`lib/CPAN/Maker.pm.in`])

- **Timestamp removed from generated `Makefile.PL`** — The `#
  autogenerated by … on <timestamp>` comment has been removed from the
  top of generated `Makefile.PL` files. This ensures that repeated
  builds from identical source produce bit-for-bit identical
  output. ([`lib/CPAN/Maker.pm.in`])

---

### Build System Improvements (Makefile / Bootstrapper)

#### Template Variable System

- Templates (`.pm.in`, `.pl.in`, `.sh.in`, `buildspec.yml.tmpl`,
  `test.t.tmpl`) now use the `cmb resolve-vars` mechanism instead of
  inline `sed` substitutions. A `gen-vars-file` make function writes
  resolved variable values to a sidecar `.vars` file consumed by
  `cmb`, enabling variables containing spaces, ampersands, or special
  shell characters to survive expansion safely.
- The `TEMPLATE_VARS` list now includes: `PACKAGE_VERSION`,
  `MODULE_NAME`, `GIT_SHA`, `GIT_DIRTY`, `GIT_EMAIL`, `GIT_USER`,
  `GIT_NAME`, `MIN_PERL_VERSION`, `PROJECT_NAME`.
- Git commit SHA (`GIT_SHA`) and dirty-state descriptor (`GIT_DIRTY`)
  are now captured at build time and available for template
  substitution.

#### Dependency Management

- `local/` directory support added: `PERLINCLUDE` now includes `-I
  local/lib/perl5`, and `local` is added as a build dependency so
  locally-installed modules are available during syntax checking.
- `cpm` and `carton` are detected and exposed as `CPM`/`CARTON` make
  variables. `CPAN_INSTALLER` selects the first available tool; a
  warning is emitted if neither is found.
- `PERL5LIB` is now cleared (`PERL5LIB=`) during `perl -wc` syntax
  checks for `.pm` and `.pl` files to prevent ambient environment
  modules from masking missing local dependencies.
- Dependency scanning (`requires`, `recommends`, `suggests`) now
  operates on `.pm.in`/`.pl.in` source files (`SOURCE_FILES_IN`)
  rather than built targets, removing a potential chicken-and-egg
  ordering issue.
- `deps.mk` generation is now atomic: output is written to `$@.tmp`
  and renamed only if non-empty, preventing a truncated `deps.mk` from
  being left behind on failure.

#### `extra-files.mk` Integration

- A new `extra-files.mk` target is generated from `buildspec.yml`. It
  adds share-directory and distribution-root files as explicit
  prerequisites of the tarball target, so changes to non-source
  distribution assets trigger a rebuild automatically.

#### Version Bump Targets

- `release`, `minor`, and `major` targets now run `clean` before
  bumping the version, ensuring no stale built artefacts persist
  across a version change.

#### GitHub Repository Creation (`git.mk`)

- New `repo` target: creates a GitHub repository via `gha-aws`
  (`GitHub::Actions::AWS`). Supports `REPO=`, `PUBLIC=1`,
  `REPO_DESCRIPTION=`, and `DRYRUN=` parameters.

#### Bootstrapper Command Rename

- The bootstrapper command has been renamed from `bootstrapper` to
  `cmb`. The `BOOTSTRAPPER` make variable now resolves to `cmb`.

#### Docker / CI Build

- `INSTALLER` variable renamed to `DOCKER_CPAN_INSTALLER` in the
  `build-ci` target to avoid conflicts with the new `CPAN_INSTALLER`
  variable used during local builds.

#### `builder` Script Fix

- Corrected an inverted conditional: branch checkout now correctly
  tests for `[[ -d ".git" ]]` (was `! [[ -d ".git" ]]`), so `git
  checkout` is only attempted inside a git repository.
- Removed a stray early-exit guard that prevented non-`REPO`
  invocations from proceeding.

#### Miscellaneous

- `find-files` macro now excludes backup and lock files (`#*`, `.#*`,
  `*~`, `*.bak`) and sorts its output for deterministic variable
  ordering.
- `extra-files.mk` and `local/**` added to `.gitignore`.
- `local.mk` added to the list of managed files maintained by
  `CPAN::Maker::Bootstrapper`.
- `config.mk` is now declared as a no-op target (`config.mk: ;`) to
  suppress "no rule to make target" warnings when the file is absent.
- `SOURCE_FILES_IN` variable introduced as a convenience alias for
  `.in`-suffixed source paths.

## Upgrade Notes

- If you use the `bootstrapper` command directly in scripts or CI,
  update references to `cmb`.
- Projects that rely on the `INSTALLER` make variable for Docker
  builds should rename it to `DOCKER_CPAN_INSTALLER`.
- Run `make update` after upgrading `CPAN::Maker::Bootstrapper` to
  pull in the updated managed include files (`perl.mk`, `git.mk`,
  `version.mk`, `update.mk`, `local.mk`).
- Syntax checking now clears `PERL5LIB` and adds `local/lib/perl5` to
  `@INC`. Run `cpm install` or `carton install` in your project root
  to populate `local/` if you have local dependencies.
